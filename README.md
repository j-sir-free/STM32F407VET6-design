2025-2026-2学期《嵌入式系统及应用》
课程设计指导手册
* 1 课程设计任务
* 1.1 课程设计作品名称：一种简易距离监测装置的设计
* 1.2 设计目的
设计一种简易的距离监测装置，采用超声波测距模块测量目标距离，在距离过近 或过远时报警，同时将测量数据、阈值信息等通过串行通信发送至上位机，或通过蓝牙无线通信传送至手机。
* 1.3 基础功能要求
（1）通过超声波测距模 HC-SRO4 获取被测物体的距离，显示在LCD屏上，格 式为“实测：1235mm ”。
（2）采用按键KEY00设置高阈值的开关，格 式为“高阈：2200mm ”；KEY01设置高阈值的开关，格 式为“低阈：1000mm ”。设置开始后，从最高位开始输入，选择矩阵键盘中的 10 个按键（代表数值 0 ~ 9）来设置测量距离的高低阈值，数值从低位往高位推，四位输完后，分别按KEY00和KEY01确认。
（3）采用按键KEY02用于警告开关状态切换，当警告功能打开时,测 量距离低于低阈值或高于高阈值，蜂吗器均鸣叫发出警告声音，同时闪烁 红色显示测量距离；
（4）在蜂鸣器告警时，通过串口将告警信息发送至上位机，告警信息内容包括： 实测距离、高低阈值及告警种类（超过高阈值限还是低于低阈值限）等。
（5）在LCD屏上显示你的姓名和学号。

* 1.4 拓展内容
（1）在蜂鸣器告警时,通过蓝牙无钱通信模块将告警信息发送至手机端，告警信息 内容包括：实测距离、高低阈值及告警种类（超过高阈值限还是低于低阈值限）等；
（2）警报发生时，从 RTC 组件中获取时间（包括年月日时分秒），并将它添加到向上位 机或移动端发送的告警信息中。
* 2 课程设计成果要求
每位同学在课程设计完成后，需要提交如下成果：
（1）全套实验代码压缩包1个
（2）演示视频
（3）课程设计报告
* 3 课程设计成绩评定说明
（1）评分标准如下：
完成任意2个基础功能的同学，方可申请“及格”成绩；
完成任意4个基础功能的同学，方可申请“中等”成绩；
完成全部5个基础功能的同学，方可申请“良好”成绩；
完成全部5个基础功能，加上至少1个拓展功能的同学，可申请“优秀”等级。
（2）每位同学完成相关设计任务后，要让老师现场验收确认，老师根据验收情况提问，同学根据老师提问进行答辩。
